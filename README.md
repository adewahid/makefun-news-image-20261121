**The World Ledger** — a one-page newspaper front page summing up the
world news of Saturday 21 November 2026: **36 stories across 7 regions**,
built for the make.fun competition `news-image-20261121` (program/v1,
free entry). Four illustrated lead stories, eight picture stories, 24
briefs with a source cited for every story, a "How the day unfolded"
timeline strip, a world map with numbered pins 1–36 matching the story
numbers, a region-count bar, a "Day in Numbers" panel, and a DATE CHECK
footer. Clean serif type on cream paper, red accent — the winner formula.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, stdlib only, 1082 lines) draws `entry.png`
(1024×1024) from scratch, pixel by pixel, using the DejaVu bitmap
glyphs in `fonts.bin` (generated by `gen-fonts.py`); it runs twice
with byte-identical output.
